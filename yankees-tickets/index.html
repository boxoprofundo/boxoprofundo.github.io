Data sources

This page is served statically from GitHub Pages — every request happens in your browser. Two marketplaces offer free public APIs that work from a browser; paste your keys below (stored only in this browser's localStorage).

With keys saved here, every Search fetches prices live at that moment.

StubHub, Vivid Seats, TickPick and XP don't offer public browser-accessible APIs, so for those the app builds direct search links for each game with your quantity applied where the site supports it. See the README for how to extend this with server-side data.
